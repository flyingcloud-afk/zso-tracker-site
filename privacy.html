Что это за приложение

«ЗСО Трекер» — личный инструмент его автора (гидрогеолога) для ведения проектов зон санитарной охраны. Приложение запускается локально на компьютере владельца. Публичного сервера, регистрации и учётных записей других пользователей нет.

Какие разрешения Google запрашиваются

Приложение запрашивает один доступ Google (OAuth scope):

  • https://www.googleapis.com/auth/drive — полный доступ к Google Drive владельца.

Этот доступ нужен, чтобы создавать папки проектов, загружать, читать, переименовывать и перемещать файлы проектов в собственном Google Drive владельца. Приложение использует доступ только к Drive самого владельца и только для этих целей.

Какие данные обрабатываются

  • Файлы проектов в Google Drive владельца (документы, PDF, таблицы) — читаются и записываются только в его Drive.
  • Метаданные и результаты разбора файлов хранятся в локальной базе данных на компьютере владельца.
  • Токены доступа Google хранятся только локально, на компьютере владельца, в файле, не передаваемом никому.

Передача данных третьим лицам

Данные не продаются, не публикуются и не передаются третьим лицам для рекламы или иных коммерческих целей.

Исключения — сервисы, которые приложение вызывает по прямой необходимости работы:

  • API Anthropic (Claude). Тексты документов проектов (извлечённые из файлов Drive) отправляются в API Anthropic для классификации файлов и подготовки черновиков глав. Это происходит по действиям владельца в приложении. Обработка на стороне Anthropic регулируется условиями и политикой конфиденциальности Anthropic.
  • Веб-поиск через API Anthropic. Для поиска справочных фактов (например, о районе или нормативных документах) используются поисковые запросы; в них содержатся названия мест и организаций, а не файлы.
  • Геокодирование (Nominatim / OpenStreetMap). Для расчёта расстояний на сервис отправляются адреса и названия мест из проектов.
  • Почта по IMAP (необязательно). Если владелец включит эту функцию, приложение читает письма из указанного им почтового ящика напрямую по протоколу IMAP с паролем, хранящимся локально. Это не относится к доступам Google, перечисленным выше.

Хранение и безопасность

Данные и токены хранятся локально на компьютере владельца и не загружаются на сервер приложения (такого сервера нет). Защита этого компьютера — ответственность владельца.

Как отозвать доступ

Доступ приложения к аккаунту Google можно в любой момент отозвать на странице myaccount.google.com/permissions: выберите приложение и нажмите «Удалить доступ». Локальные данные можно удалить, стерев папки data/ и credentials/ приложения.

Privacy Policy (English summary)

Last updated: October 26, 2026.

ZSO Tracker is a personal tool of its author (a hydrogeologist) for managing sanitary protection zone projects. It runs locally on the owner's computer. There is no public server and no accounts for other users.

Google permissions. The app requests one OAuth scope: https://www.googleapis.com/auth/drive (full access to the owner's Google Drive). It is used only to create folders and to read, write, rename and move project files in the owner's own Drive.

Data handling. Project files are read and written only in the owner's Google Drive. Metadata and analysis results are stored in a local database on the owner's computer. Google access tokens are stored locally only.

Sharing. Data is not sold and not shared with third parties for advertising or commercial purposes. Exceptions, necessary for the app to work: (1) text extracted from project documents is sent to the Anthropic (Claude) API for file classification and chapter drafting, subject to Anthropic's terms and privacy policy; (2) web-search queries made via the Anthropic API contain place and organization names, not files; (3) addresses and place names are sent to Nominatim (OpenStreetMap) for geocoding; (4) optionally, if the owner enables it, a mailbox is read over IMAP with locally stored credentials (separate from Google access).

Revoking access. You can revoke the app's access at any time at myaccount.google.com/permissions. Local data can be removed by deleting the app's local data/ and credentials/ folders.
